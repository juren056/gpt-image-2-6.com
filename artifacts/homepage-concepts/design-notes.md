# 三个首页方向

只重做首页。生产代码没动。三版都是普通 HTML/CSS 加少量 SVG，没有 WebGL、视频或付费图。迁到现有 React 时，每个大块对应一个组件，样式可以改写成 Tailwind。

定稿标记用 `assets/logo.svg`（按附件图标重绘；上线请换回原始 PNG）。画面都标明是视觉示意，不是模型结果。没有用户数和评分。

草案仍是 Free · 3 credits，静图 1 点，8 帧 GIF 3 点，积分包 $9.90 / $19.90 / $39.90，一次性。

## A 电影海报 `a/`

适合要第一眼像片子、而不是后台的品牌首页。首屏是满屏海报、巨号衬线标题、胶片孔时间轴和一条字幕式 prompt。下面按 GIF、SVG、PNG 三条满屏分镜往下讲，不是卡片墙。

组件：`PosterHero`、`FilmStrip`、`FormatChapter`、`CutList`、`CreditClose`。

## B 明亮杂志 `b/`

适合想彻底离开深色工具页的品牌。纸色底、超大 GIF、右侧一整块纯色版面、三张高低不一的展签、一张价目表。结构就是刊头、封面、展墙、短文、价目。

组件：`Masthead`、`CoverSpread`、`Exhibition`、`Essay`、`RateCard`。

## C 播放画布 `c/`

适合强调「这是创作空间」。浅色场地、一块偏右的画布、四张可复用的参数贴纸、底部一条时间轴。下面是三种素材和一行图例。贴纸是同一个组件换文字。

组件：`PlayNav`、`CanvasStage`、`Sticker`、`Timeline`、`MaterialRow`、`StartBand`。

## 推荐

优先做 **B**。黄总否定的是深色卡片堆砌，B 的排版距离最远，而且色块、巨字、表格都能直接落成 Tailwind，不靠特效。

若更在意打开页面的那一下，用 **A** 做营销首页，工作室里再放 C 的画布。C 最像产品，但贴纸多，实现时要守住留白，不要加回侧栏表单。
