# 生成器视觉微调

对照的是仓库里的 `src/components/banana-generator.tsx` 和 `src/styles/banana-generator.css`，以及首页上它前面的顶栏和 hero。不是后面那几版实验稿。

生产 `src` 没有改。两版都是静态 HTML，操作用的是原来的控件，按钮不会提交。

## 完全没动

- 左右分栏：左表单，右预览。窄屏改为上下，和现在 `@media (min-width: 1024px)` 的规则一致。
- 页顺序：顶栏、hero、生成器。
- 页签仍是 Text to image / Image to image，不是新的格式页签。
- 控件仍是：Agent 入口、模型、Prompt、示例短句、比例、分辨率、输出张数、费用、生成按钮、Prompt tools。
- 未登录时余额是「—」。空 prompt 时按钮是「Please write a prompt first」，不能按。这是现有禁用逻辑，不是新流程。
- 分辨率仍是 1K / 2K / 4K，积分仍是模板上的 8 / 12 / 28。没有帧数、循环、胶片或新价格。
- 没有电影时间轴、巨字、贴纸、第三栏，也没有新功能。

## 两版都改了的样式

- 顶栏标记换成定稿蓝紫画框星光 logo。页面仍是近黑底，没有铺大紫或大青。
- 文案只把产品说成 GPT Image 2.6，并写明文件可以是 GIF、SVG 或 PNG。模型副标题同样这一句。
- 面板圆角 14px，输入框圆角 10px，多了一层很轻的投影。
- 栏距从 16px 收到 14px，标签 13px / 600，正文仍约 14px。
- 选中项仍是描边加淡底，焦点环仍在。
- 空预览写清楚：还没有文件，生成后才会出现 GIF、SVG 或 PNG。示例图是示意，点了只准备 prompt，不会扣费。

## A

最接近现模板。主色仍是原来的黄 `#facc15`。左栏大约 360–420px。Prompt 为空，按钮禁用。预览是虚线空状态，下面仍是四格示例。

## B

只比 A 多两处，结构相同。

- 左栏收到 320–360px，预览更宽，中间放一块标明「不是生成结果」的示意框。
- Prompt 里有一句示例，按钮变成可按的 Generate image，高度 48px，颜色换成 logo 里的蓝 `#3d4ed8`，字是浅色。选中态跟着这个蓝，不再用黄。页面其他地方不变黄，也不铺渐变。

## 建议

若要几乎看不出换过产品，用 A。若希望生成按钮和预览稍清楚、又不愿改操作，用 B。
