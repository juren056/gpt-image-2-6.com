# 首页生成器，三个方向

只做生成器。顶部是品牌和一句 H1，生成器占首屏。整页概念停在上一轮，生产代码没改。

三版都是普通 HTML/CSS 加一张 SVG。没有 WebGL，没有视频。手机端在 800px 以下改成上下堆叠，1440 和 390 都查过，没有横向溢出。

画面里的星和路径是视觉示意，不是模型结果。GIF 草案成本是 8 帧、循环、1:1，3 credits。

## A 导演监视器 `a/`

大预览在上，胶片在中，控制条在下。预览停在第 3 帧，0.38 秒。胶片上的星从左走到右，第 3 格有播放头，不是八张相同缩略图。Prompt 带 Example 标签。Cut GIF 是整条右端的主按钮。

适合 GIF 作为主产品。时间、帧号、成本、按钮在一条视线里。

组件：`MonitorScreen`、`FilmStrip`、`ControlBar`。手机顺序：预览、胶片（四列折行）、控制条改成一列。

## B 创作轨道 `b/`

左轨是三步：格式、带示例的 prompt、导出说明。中间是画布、一条带播放头的时间尺、整宽 Generate GIF。右边是打开的 GIF 参数：比例、帧数、循环、3 credits。参数都在，但不占主操作。

适合要把路径教清楚的时候。它最接近表单，所以不要再加卡片。

组件：`FormatStep`、`PromptStep`、`Stage`、`Timeline`、`SettingsDrawer`。手机顺序：轨道、画布、抽屉。

## C 命令条 `c/`

这是空状态。舞台写明 Nothing generated yet，并给出可试的一句。格式和 GIF 参数是舞台上的小药丸。时间轴停在 0.0 秒、第 1 帧，表示还没生成。底部一条命令：格式、输入、3 credits、Generate。

适合作为默认空状态，也是最少界面的一版。

组件：`Stage`、`ContextPills`、`Scrubber`、`CommandBar`。手机上命令条折成两行，按钮仍在右下。

## 推荐

首页生成器用 **A**。黄总要看的是生成器本身，A 把预览、有播放头的时间轴、prompt 和主按钮收成一台监视器，GIF 的帧、循环、比例和积分都在控制条上。

C 的空状态文案可以直接放进 A 的预览：还没生成时换掉示意画面。B 的参数不要常驻，帧数超过三个选项时再开抽屉。
