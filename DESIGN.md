# Creative workspace direction

Use the approved banana mark with warm yellow actions, olive-black surfaces and a restrained green focus ring. Use self-hosted Manrope Variable for English and numerals, and Noto Sans SC Variable for Simplified Chinese. Headings use weight 600, normal Chinese tracking and slightly tight English tracking. Body copy uses 15–16px with 1.65 Chinese / 1.55 English leading; controls use weight 500 and financial values use tabular numerals. Preserve native fallback fonts for other scripts. Remove the reference site's yellow haze and dotted background. Compose the homepage as a task selector and editable brief, followed by the actual generator. Use explicitly labeled original vector workflow illustrations, never fabricated generation proof. `scripts/create-workflow-art.mjs` is the source for the seven explanatory SVGs; the old borrowed raster files and their download script have been removed.

Marketing helps users choose a task. The workbench exposes inputs, cost, processing status and next actions. The account home prioritizes returning to a saved project. At narrow widths use one column and generous touch targets. Honor reduced motion, keyboard focus, light/dark themes and truthful unavailable states.
