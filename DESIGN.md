# Creative workspace direction

Use the approved banana mark with warm yellow actions, olive-black surfaces and a restrained green focus ring. Use the already self-hosted Libre Baskerville for the hero and Inter Variable for the interface. Remove the reference site's yellow haze and dotted background. Compose the homepage as a task selector and editable brief, followed by the actual generator. Use explicitly labeled original vector workflow illustrations, never fabricated generation proof. `scripts/create-workflow-art.mjs` is the source for the seven explanatory SVGs; the old borrowed raster files and their download script have been removed.

Marketing helps users choose a task. The workbench exposes inputs, cost, processing status and next actions. The account home prioritizes returning to a saved project. At narrow widths use one column and generous touch targets. Honor reduced motion, keyboard focus, light/dark themes and truthful unavailable states.
