# Reference decisions

- Freepik/Magnific: category-led discovery and a compact first action.
- Pollo AI: model directory separated from task directory.
- Photoroom: upload-first product workflows.
- Leonardo/Krea: outcomes and use cases carry more weight than model icons.
- Recraft: vectorization and SVG editing are separate tasks.

No competitor code, logos, customer work, rankings, traffic claims or conversion statistics were copied. Existing site-owned images are labelled as purpose illustrations unless their exact model provenance is verified.
