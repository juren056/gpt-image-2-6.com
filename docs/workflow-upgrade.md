## 真实限制

- 线上公开模型状态显示 fal 凭据未配置；这次不会开启未验收模型。真实出图、模型对比证据和费用实测需要接入凭据后完成。
- 支付流程保留配置就绪判断，接入支付商户凭据前不能把按钮描述成可付款。未执行真实收费。
- 新增界面文案提供英文与中文；其他语言的新文案暂使用英文，仍需本地化。场景提示词使用英语，以便跨语言复用。
- 现有动态翻译查询仍导致大型公共消息包；静态 HTML 保证页面可读，但完整交互的下载成本仍需专项优化。不能据此宣称 Lighthouse 或核心网页指标已经达标。
- 本地 Vite 开发服务出现模块加载超时，采用正式静态产物与线上浏览器验证；没有修改框架基础设施来绕过错误。
