# Navigation Behaviors

- Desktop tool menus open on hover or keyboard focus and close when focus/hover leaves.
- Each trigger includes a chevron whose orientation reflects the open hover/focus state.
- Dropdown rows are full links with an icon, concise title, and muted one-line description.
- Mobile tool groups use native disclosure controls and close the full mobile menu when a tool is selected.
- Existing direct navigation, external-link handling, authentication, locale, and theme behavior is preserved.
- The header remains sticky with the current translucent background and backdrop blur.
