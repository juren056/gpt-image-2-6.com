# Homepage prompt library behaviors

- Source module exposes 56 prompts across eight categories.
- Category selection, search, copy, empty state, and incremental load-more are preserved.
- The Qwen port uses static preview images and does not autoplay source videos.
- Homepage placement is immediately below the generator so visitors can generate first or browse prompts next.
- Header gains a direct Prompts anchor and removes one redundant top-level entry to reduce crowding.
