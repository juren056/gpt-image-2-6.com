# Navigation Refresh Topology

## Scope

Only the global marketing header is changing. The homepage generator section, its
`#generator` anchor, and all page sections below the header remain unchanged.

## Desktop order

1. Brand link
2. Home link (`/#generator`)
3. AI Tools dropdown
4. AI Image dropdown
5. AI Video dropdown
6. Pricing link
7. Guides link
8. Existing locale, theme, authentication, and user controls

## Mobile order

The same links appear inside the existing menu drawer. Tool groups expand inline;
the existing locale, theme, and authentication controls remain at the bottom.
